# Who's That Pokémon Card?

A guessing game built around Pokémon trading cards. Pick which hint categories
are in play, then reveal hints one at a time — flavor text, genus, type,
stage, attack/ability, and the card's illustration — and try to guess the
Pokémon before you run out of hints. Guessing correctly with fewer hints
revealed earns more points.

## Development

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build
- `npm test` — run the test suite (Vitest)
- `npm run lint` — lint the codebase (Oxlint)

## Stack

React, TypeScript, Vite, Tailwind CSS, and shadcn/ui components (Radix
primitives).
